# Producto-Final-ED_EJ26_EQ1
Simulador experimental de la Ley de Enfriamiento/Calentamiento de Newton con adquisición de datos en tiempo real vía Arduino (MAX31855 + LM35). Calcula α y k analíticamente, compara modelo teórico vs datos reales con R², MAE y error porcentual. Interfaz web con Web Serial API , Chrome/Edge.
